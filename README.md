# DiM-SoTiS // Каталог утилит и приложений (Windows & Android)

Общий открытый каталог всех выпущенных нами бесплатных утилит и приложений для **Windows** и **Android**.  
У каждого проекта — свой публичный репозиторий с исходным кодом, подробным описанием и готовой сборкой (`.exe` / `.apk`) в GitHub Releases.

## Выпущенные релизы

| Проект | Платформа | Версия | Описание | Ссылки |
| :--- | :---: | :---: | :--- | :--- |
| **Multi-Monitor Tray Dimmer** | Windows | `v1.0.0` | Лёгкая нативная утилита в трее (Rust, ~155 КБ) для раздельной регулировки яркости и затемнения каждого монитора по DDC/CI + оверлей и глобальным хоткеям. | [Репозиторий](https://github.com/DiM-SoTiS/multi-monitor-tray-dimmer) · [Скачать (.exe)](https://github.com/DiM-SoTiS/multi-monitor-tray-dimmer/releases/latest) |
